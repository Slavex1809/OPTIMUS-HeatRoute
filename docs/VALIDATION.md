## Границы испытаний

50 клиентов каждый загрузили, рассчитали и выгрузили небольшое задание из линии и одной цели. Это не 50 одновременных больших расчётов.

Файл 3 ГиБ содержит два географических объекта и заполнение JSON-пробелами. Файл 500 МиБ содержит корректный малый расчётный GeoJSON с заполнением пробелами в изолированном тестовом хранилище. Проверки подтверждают HTTP-передачу и дисковую обработку, но не расчёт 3 ГиБ сложной геометрии или создание 500 МиБ реальных трасс. Один большой Feature и метаданные объектов занимают память; крупный рабочий набор требует отдельного испытания.

Java SolutionVerifier проверяет ограничения выбранного cost, камеры, связность, пересечения, расходы и непрерывные длины. Python-проверяющий независимо проверяет выходные связи, расходы, диаметры, суммы и ранжирование. Полное формальное соответствие спорному правилу ввода не подтверждено; см. COMPLIANCE.md.
