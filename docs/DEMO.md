# Сценарий демонстрации

1. Продукт и задача подключения ОКС.
2. Обратный поиск: сначала прямые вводы, затем общая трасса и улучшение стоимости.
3. Открыть сервис, загрузить corrected.geojson, запустить все 17 целей. Скриншот в презентации получен из настоящего интерфейса.
4. Показать точки 2, 5 и 10 и прямые вводы. Применяется cost, глобальная ближайшая граница отдельно не проверяется.
5. Сравнить три варианта по S; все 17/17, лучший 431,31 млн ₽, штраф 0.
6. Показать расходы, минимальные ДУ, непрерывные длины и спецпроходы. Выгрузить GeoJSON и открыть протокол.
7. Объяснить Java 11, JTS, PostgreSQL/PostGIS и запуск Ubuntu/Compose.
8. Передать исходники, JAR, данные, презентацию и документацию. Следующие этапы — целевая инфраструктурная приёмка и крупные рабочие наборы.

Расчёт занимает несколько минут. Для короткой защиты сначала покажите сохранённую карту, затем запустите новый расчёт. Не называйте сохранённые данные результатом только что выполненного запуска. Полный сценарий: sudo bash scripts/acceptance-contest.sh.
